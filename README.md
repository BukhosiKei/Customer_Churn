# Customer Churn Prediction

A machine learning project focused on analysing customer churn and predicting whether a customer is likely to leave a service.

This project was developed as part of my **Data Science studies** and demonstrates an end-to-end machine learning workflow using Python.

## Overview

Customer churn is an important business problem where organisations aim to identify customers who may discontinue their service.

This project explores customer data, prepares it for machine learning, trains a predictive model, and evaluates its ability to identify potential churn.
